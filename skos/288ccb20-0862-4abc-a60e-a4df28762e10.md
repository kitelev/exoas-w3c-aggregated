# skos__exactMatch

Стандартное свойство соответствия W3C SKOS <http://www.w3.org/2004/02/skos/core#exactMatch>: понятия можно уверенно взаимозаменять в широком круге задач поиска (высокая степень уверенности, транзитивно по W3C).

- **Где применяется:** утверждения соответствия «стола» сравнения авторов (`$desk-mappings`) — `exo__Statement` [понятие автора, `skos__exactMatch`, нейтральное понятие стола]. Предикат в утверждении — **голым UID** этого ассета, не ссылкой по имени (RFC `14217015` §CQ4, AC8; шаг стола скилла `exoize-source` отвергает ссылку по имени до записи).
- **Пример:** «Я» автора A ↔ «Самость» стола.
- **domain:** `exo__Asset` · **range:** `skos__Concept` · кратность — множественная. Решение по мандату фаундера 2026-10-11 23:18 (фаундер вправе пересмотреть): range узкий — CLI SHACL проверяет его через утверждение адаптера стола `concept__Concept ⊂ skos__Concept`; domain широкий — иначе без того же ребра субъект не проверялся бы вовсе (находка ревью PR kitelev/exocortex#4558).
- **Вывод SKOS** (симметричность, транзитивность, обратность) движок не делает — запросы стола на нём не строятся.

Источник: RFC `14217015-963b-4020-b267-fd13b1275b3a` §5; лист `6d3d7dd2-e379-4d2d-b655-080df7cba88e`.
